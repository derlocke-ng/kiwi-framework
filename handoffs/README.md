# Handoffs

Changes that another repository needs because of work here, written for the session that will make them. A session on kiwi-framework or Armory does not change other repositories itself (the owner's rule, see `CLAUDE.md`): it writes a file here, `<repository>-<topic>.md`, and says so in its report. The owner starts a session for that repository (or a cloud session is started for it, with the owner's approval) and points it at the file; that session asks the owner before it pushes.

A handoff says: what to change and why, which files, the change itself as exactly as it is known, what is not known yet and must be checked, how to test it, and what done looks like. When the change has landed, the file is deleted in the next commit here, with a line in the message saying where it landed.
